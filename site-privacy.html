Webサイトのプライバシー

最終更新日: 2026年9月21日

このページは、まいにちウォーク公式Webサイトにおけるアクセス情報の取扱いについて説明するものです。

アプリ本体の歩数・体重などのデータの取扱いについては、アプリのプライバシーポリシーをご確認ください。

1. Webサイトのアクセス解析について

本サイトでは、記事やサポート情報がどの程度利用されているかを把握し、内容の改善に役立てるため、Webアクセス解析を利用する場合があります。

現在の状態

2026年9月21日時点では、Cloudflare Web Analyticsによる計測はまだ開始していません。 計測を開始する際は、このページの内容を実際の運用に合わせて更新します。

2. Cloudflare Web Analyticsを利用する場合

導入時は、Cloudflare Web Analyticsを使用して、サイト全体の訪問傾向を把握する予定です。

確認する情報の例は次のとおりです。

  • 訪問数、ページ表示数
  • 閲覧されたページ
  • 参照元サイト
  • 国、端末種別、ブラウザ、OSなどの大まかな利用環境
  • ページの表示性能

CloudflareのWeb Analyticsは、利用状況メトリクスの収集にCookieやlocalStorageを使用せず、IPアドレスやUser-Agentなどを使って個人をフィンガープリントしない仕組みと説明されています。個々の利用者を継続的に識別して追跡することを目的とはしません。

Cloudflare Web Analyticsの説明

3. Google検索について

Google検索で本サイトがどのように表示・利用されているかを把握するため、Google Search Consoleを利用する予定です。検索結果での表示回数、クリック数、検索クエリなど、Googleが提供する集計情報を確認します。

4. アプリのデータとは結び付けません

Webサイトのアクセス解析情報を、まいにちウォークのアプリ内にある歩数・体重・目標歩数・体重予測などのデータと結び付けることはありません。

5. App Storeへのリンクについて

本サイトからApp Storeへの案内には、どの記事・ページからApp Storeへ進んだかを集計するため、App Store ConnectのCampaign Linkを利用する場合があります。

6. この説明の変更

利用する解析方法やWebサイトの機能を変更した場合は、実際の運用に合わせてこのページを更新します。
